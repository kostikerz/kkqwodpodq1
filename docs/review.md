# Результат повторной проверки

Проверка проведена 17 ноября 2026 после первоначальной передачи проекта.
Исправления включены в последний, пятый коммит; исходная история
репозитория и разделение работы на пять этапов сохранены.

## Найденные и исправленные ошибки

1. URL с нечисловым/недопустимым портом или пробелом принимался на этапе 1.
   Теперь ошибка выявляется при чтении конфигурации.
2. Ошибки zlib и HTTP IncompleteRead не перехватывались CLI.
   Теперь выводится сообщение Error с кодом 1 без traceback.
3. Разбор зависимостей принимал некорректный хвост строки, например
   `libc6???` или `libc6 (nonsense)`, молча отбрасывая его.
   Теперь проверяется весь синтаксис имени, архитектуры и версии.
4. Команды в разделах этапов 1/2 README запускали этап 5 по умолчанию.
   Добавлены явные аргументы `--stage 1` и `--stage 2`.
5. Формулировка о доступности артефактов GitHub Actions была неточной.
   Теперь прямо указано, что workflow ещё не запускался.

## Доказательства проверки

- 31 тест проходит, включая новые регрессионные проверки найденных ошибок.
- Все 512 ориентированных графов из трёх вершин проверены с петлями.
- 10 240 комбинаций графа/корня/глубины/фильтра проверены независимым BFS.
- SCC всех 512 графов проверены через взаимную достижимость вершин;
  проверен порядок каждого ребра между разными компонентами.
- Настоящий индекс Ubuntu повторно разобран: 6099 пакетов.
- Настоящий PlantUML повторно создал PNG apt (35/55), bash (8/10),
  coreutils (9/13); числа означают вершины/рёбра.
- Ruff E,F,I,N проходит; Python-строки <= 80 символов,
  функции <= 40 строк, сложность функций Radon <= 10.
- Git bundle и ZIP проверены; исходники и история включены в передачу.

Сравнение с apt требует запуска на Ubuntu. В текущей Windows-среде
Linux/WSL отсутствует. Публикация ранее остановилась из-за отказа доступа
Git Credential Manager к сохранённым учётным данным. Эти ограничения
не подменяются утверждением об успешной проверке или публикации.
