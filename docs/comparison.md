# Сравнение с apt

## Методика

Индекс: Ubuntu 24.04 noble, main, amd64, без updates/security/universe.
Пакеты для сравнения: apt, bash, coreutils. Команды на Ubuntu 24.04:

```sh
sudo apt-get update
sh scripts/compare_apt.sh
python3 -m src.cli configs/apt.csv --stage 4
```

Скрипт сохраняет `apt-cache policy`, `apt-cache depends`, `apt-cache dotty`
и `apt-get --simulate --no-install-recommends install` отдельно для каждого
пакета. Для точного сопоставления необходим одинаковый индекс, архитектура
и состояние установленных пакетов; policy позволяет проверить версии.
apt вызывается только как независимый эталон, не для построения нашего графа.

## Порядок загрузки

Наш результат задаёт зависимости перед потребителями на конденсации графа.
Группа cycle означает, что строгого порядка внутри неё нет.
Например: ромб A→B,C; B→D; C→D даёт D, затем B/C, затем A.
Цикл A→B→C→A выдаёт одну группу A,B,C. Одинокая A - один шаг.

apt-get в режиме симуляции показывает план установки/распаковки/настройки,
а не обязательный порядок скачивания. Скачивание apt может идти параллельно.
Поэтому эти последовательности нельзя считать тождественными.
apt учитывает уже установленные пакеты, версии, альтернативы, конфликты,
Recommends и Essential. Наш анализ показывает все альтернативы Depends и
Pre-Depends, не выбирает версии и не имеет локальной базы установок.
Внутри циклов apt разделяет распаковку и настройку, а наш вывод группирует
цикл. Различный порядок независимых вершин также допустим.

## Графическая визуализация

Стрелка нашего PlantUML идёт от пакета к зависимости. apt-cache dotty
использует Graphviz DOT, специальные формы для виртуальных/отсутствующих
пакетов и типы рёбер; наш формат упрощён, неизвестные пакеты помечаются.
Ограничение глубины и фильтр нашего инструмента сокращают граф.
Полный dotty может быть существенно больше демонстрации глубины 2.

## Статус проверки эталона

В среде выполнения Windows отсутствуют Ubuntu, WSL-дистрибутив и apt.
Команды apt здесь не запускались; их вывод и экспериментальное совпадение
не заявляются. Приведённое сравнение - сопоставление семантики и форматов,
а не выдуманный протокол запуска. Скрипт позволяет завершить проверку
на Ubuntu с реальной базой apt. Получение индекса и работа нашего
анализатора проверяются отдельно на настоящих метаданных Ubuntu.
