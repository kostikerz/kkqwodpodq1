# Протокол проверки

Дата: 17 ноября 2026. Среда: Windows, Python из bundled runtime Codex,
Java 1.8.0_511, официальный PlantUML 1.2025.2, раскладка Smetana.

## Автоматические тесты

Команда: `python -m unittest discover -v`.
31 тест пройден. Проверены шесть параметров CSV и ошибки формата,
HTTP на mock-границе, четыре формата индекса, прямые зависимости,
версии/альтернативы/Provides, ромб, циклы и петля, фильтрация, глубина 0/1,
повторное раскрытие при коротком пути, неизвестный пакет, цепочки длины
2000, порядок SCC, сериализация PlantUML, ошибки Java/JAR и команды CLI.
Дополнительно сохранён небольшой срез настоящих метаданных Ubuntu
в tests/fixtures/ubuntu.Packages: регрессионный тест воспроизводит числа
вершин и рёбер всех трёх примеров без доступа к сети.

Проверка оформления: Ruff (E,F,I,N) успешно, длина строк Python <= 80,
функции <= 40 строк, цикломатическая сложность Radon <= 10,
числовых литералов в сравнениях нет. `git diff --check` без ошибок.
Примеры всех этапов и ошибок каждого параметра:
[demonstration.md](demonstration.md).

## Повторная проверка

При повторном аудите исправлены неполная проверка URL (пробелы и порт),
необработанные ошибки zlib и HTTP IncompleteRead, принятие некорректного
остатка строки зависимости и команды этапов 1/2 в README.

Добавлена независимая исчерпывающая проверка: все 512 ориентированных
графов из трёх вершин, включая петли. Для каждого проверены глубины 0-3,
три корня и фильтр B: всего 10 240 обходов DFS сверены с эталонным BFS.
Для всех 512 графов проверены SCC через взаимную достижимость и порядок
каждого межкомпонентного ребра. Ошибок алгоритмов не обнаружено.

После повторной проверки проект опубликован в GitHub. Успешный запуск
Actions 44161177354 создал настоящий вывод apt. Переданный пользователем
артефакт изучен; фактическое сравнение добавлено в comparison.md.

PNG созданы настоящим локальным PlantUML через Java, открыты и проверены

Граничные вершины не раскрываются, поэтому отсутствие метаданных за
границей анализа не проверяется. Это порядок ограниченного графа,
а не полный план установки apt.

## Реальная эталонная проверка на Ubuntu

Локальная среда остаётся Windows без apt, но эталон действительно выполнен
в GitHub Actions на Ubuntu 24.04. Сохранены исходные результаты и версии.
Прямые зависимости и графы глубины 2 совпали для трёх пакетов.
Симуляция apt дала пустой план, поскольку пакеты уже установлены;
отличие от статического порядка нашего инструмента объяснено.
Непустой план установки в этом эксперименте не проверялся.
Подробности: [comparison.md](comparison.md).
